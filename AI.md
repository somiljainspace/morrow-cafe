# AI Usage

## Tools used

* ChatGPT
* Claude Code

## What I used AI for

I used AI to help with the initial project setup, component structure, API mock implementation, form validation, responsive styling, accessibility considerations, and debugging. I also used it to review the implementation against the assignment requirements and suggest improvements.

## One useful thing AI helped with

AI helped me quickly identify and implement the complete claim flow: form validation → loading state → API request → error handling → success state with the claim code. It also helped me catch small implementation issues while running the lint and production build.

## One thing AI got wrong or that I changed

AI initially suggested some implementation details that were more complex than necessary for this assignment. I simplified them to keep the code focused, avoid unnecessary dependencies, and stay within the intended 3–4 hour scope.

## What I personally reviewed

I personally reviewed the UI, responsive behavior, form validation, API flow, loading/error/success states, accessibility basics, animations, code structure, and production build. I also tested the application locally and made changes where the generated implementation did not match the intended user experience.
